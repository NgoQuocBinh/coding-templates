# Coding Templates

A collection of reusable templates for **Competitive Programming** and **Problem Setting**.

The goal of this repository is to keep commonly used boilerplate in one place, making it easy to start working without rebuilding the same setup from scratch.

## Templates

### Competitive Programming

Templates for quickly setting up a Competitive Programming solution.

| File | Description |
| --- | --- |
| [`no_subtasks.cpp`](./Competitive%20Programming/no_subtasks.cpp) | C++ template for problems without subtasks |
| [`contain_subtasks.cpp`](./Competitive%20Programming/contain_subtasks.cpp) | C++ template for problems with subtasks |

These templates provide a clean starting point for solving programming problems and can be customized depending on the contest or problem requirements.

### Problem Setting

Templates for writing and formatting programming problems.

| File | Description |
| --- | --- |
| [`TASKS_LATEX.tex`](./Problem%20Setting/TASKS_LATEX.tex) | LaTeX template for writing problem statements |

## Purpose

This repository is primarily a **personal collection of reusable templates**.

The templates may evolve over time as I discover better workflows, useful snippets, or more convenient configurations.

Feel free to use, modify, and adapt them for your own projects.

## Languages & Tools

- **C++** — Competitive Programming
- **LaTeX** — Problem Setting

## Notes

These templates are intentionally kept simple and lightweight.

They are designed to help get started quickly rather than provide a complete framework.

> **Build once. Reuse everywhere.**
